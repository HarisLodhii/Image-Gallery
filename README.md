Image Gallery

This is a simple Image Gallery Website built using HTML, CSS, and jQuery Lightbox. 
It displays a collection of images in a clean and responsive layout. When you click on an image, 
it opens in a lightbox view with navigation and captions.

Features
Clean and simple image gallery layout
Responsive design for different screen sizes
Click any image to view it in a lightbox
Image titles and navigation inside the lightbox

🛠️ Technologies Used
HTML
CSS
jQuery Lightbox
